# Traffic Light Control System - Embedded Systems Project (IS1300)

A modular, real-time traffic light control system developed as the final project task for the course **IS1300 Embedded Systems** at KTH Royal Institute of Technology. The system manages a complex traffic intersection with multiple car lanes and a pedestrian crosswalk using state-machine logic and specialized hardware peripherals.

## Hardware Platform
* **Microcontroller:** STMicroelectronics STM32L476RG (32-bit ARM Cortex-M4 CPU @ 80 MHz)
* **Shield/Peripherals:** Traffic Light Shield (equipped with directional car traffic lights, pedestrian signals, crosswalk request buttons, and a potentiometer)
* **Display:** SSD1306 OLED Screen (connected via I2C)

## Features & Implementation Details
This repository contains the complete implementation of **Tasks 1, 2, and 4** from the project specification, ensuring fully integrated logic across all modules.

* **Task 1: Pedestrian Crossing Logic**
  * Implemented an advanced pedestrian crosswalk control with dynamic indicator light toggling (`toggleFreq`).
  * Strict timing constraints ensuring car signals transition through predefined safety sequences (Red -> Orange -> Green / Green -> Orange -> Red) using `orangeDelay` and `walkingDelay` constants.

* **Task 2: Road Crossing Management**
  * Developed collision-free intersection control preventing overlapping vehicle paths (supporting straight and right-turn lanes).
  * Smart traffic adaptation: Automatically cycles green lanes when idle (`greenDelay`), holds green for active lanes, and grants immediate priority access if an isolated car arrives at a red light.

* **Task 4: Real-Time Visualization & Dimming**
  * Integrated the `stm32-ssd1306` library to visualize remaining countdown timers on the OLED screen.
  * Timers (Pedestrian, Walking, Green, and Red delays) are rendered dynamically as graphical bars that reduce in size in real time.
  * Implemented hardware dimming: Reads the analog voltage from the shield's potentiometer to adjust the global brightness of all active LEDs proportionally.

## Repository Structure
* `/Core` - Contains all core source code (`/src`, `/inc`, and `/startup`) including main logic, state machines, and peripheral configurations.
* `/Drivers` - Hardware Abstraction Layer (HAL) files and driver configurations generated by STM32CubeIDE.

## Tech Stack & Development Tools
* **Language:** C / Embedded C
* **IDE:** STM32CubeIDE
* **Framework:** Hardware Abstraction Layer (HAL)
* **Methodology:** Test-Driven Development (TDD)
